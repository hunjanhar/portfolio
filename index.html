NewsSphere

NewsSphere is a full-stack news aggregation and community application built to deliver a fast, responsive user experience while processing high-volume news data in real time. The frontend interface is developed with React to handle interactive views, smooth page navigation, user registration, article commenting, and contact submissions. The backend service is engineered using Node.js and Express, connected to a MongoDB database for persisting application data, and integrated with a high-speed Redis caching layer. By caching API responses from external news sources, the platform minimizes external API load, reduces backend execution time, and speeds up data delivery for users.

To ensure uniform runtime environments across local development and production, every tier of the application is containerized using Docker. The infrastructure runs on Amazon Web Services (AWS), hosted on an EC2 instance configured with a Minikube Kubernetes environment. The entire cloud setup—including custom virtual private cloud (VPC) network boundaries, isolated subnets, security group rules, IAM execution roles, and server storage—is defined programmatically using Terraform. System dependencies, container engine runtimes, tool installations, and cluster configurations are automatically applied across the host using Ansible automation playbooks.

The release workflow is managed through an automated, dual-stage Jenkins pipeline integrated with ArgoCD to enable declarative GitOps deployments. Code updates trigger automated build validation, unit testing, secret scanning with TruffleHog, static code analysis with SonarQube, and container vulnerability scanning with Trivy. Application secrets are securely stored and fetched using HashiCorp Vault. Once images are built and pushed to the registry, ArgoCD syncs the target cluster state to deliver smooth updates without service interruption, while Prometheus and Grafana monitor resource utilization, cluster health metrics, and active application services.
